## 一、这是什么

一个跑在你自己电脑上的期货行情看盘工具。核心特点：

- **零成本数据**：默认走新浪财经公开接口，不需要注册、不需要 Token、不需要付费行情。
- **零依赖运行**：后端是纯 Python 标准库实现，不需要 `pip install` 任何东西。
- **单文件 EXE**：已打包好 `期货行情面板.exe`，双击即用，目标电脑连 Python 都不用装。
- **真正的加权指数**：新浪没有加权指数（`XX99` / `XX888` 实测为空），本项目用**全部在交易合约按持仓量加权**本地合成，并与天勤官方指数交叉验证偏差 < 0.05%。

> ⚠️ **免责声明**：本项目仅用于技术学习与行情查看，所有数据来自第三方公开接口，
> 可能存在延迟或错误，**不构成任何投资建议**。据此交易的风险由使用者自行承担。

## 二、两种运行方式

### 方式一：双击 EXE（推荐，无需 Python）

1. 从 [Releases](https://github.com/chenzhuanxin/domestic-futures-panel/releases) 下载 `futures-panel-v1.0.0.exe`；
2. 放到任意文件夹，**双击运行**；
3. 会弹出一个黑色控制台窗口，显示面板地址与行情连通状态；
4. 稍等几秒，浏览器自动打开 `http://127.0.0.1:8686/`。

```text
============================================================
  国内期货行情面板  ·  数据源：新浪财经
============================================================
  · 默认合约：SA2701
  · 运行方式：单文件 EXE（资源目录 C:\Users\...\Temp\_MEI123456）
  · 天勤（快期）：已启用（内置配置）
  · 当前状态：交易中
  · 行情连通：纯碱2701  1001.0  -9.0 (-0.89%)  更新于 2026-10-09 23:00:00
  · 合约列表：共 14 个挂牌合约，主力 = SA2701
------------------------------------------------------------
  面板地址：http://127.0.0.1:8686/
  提示：把 tianqin.json 放到本 EXE 同目录，可覆盖内置账号
  按 Ctrl+C 退出
============================================================
```

**注意事项**：

- **首次启动较慢（5~20 秒）**：单文件 EXE 每次启动都要把约 74 MB 解压到临时目录，属正常现象，不是卡死。
- **关闭方式**：关掉那个黑色控制台窗口，或按 `Ctrl+C`。
- **保留黑窗口是有意的**：启动失败时能直接看到报错原因；如果你更想要纯净体验，可以自己重新打包时把 `console=True` 改成 `console=False`（见[第十六节](#十六自己重新打包-exe)）。
- 若提示"未配置 Python"之类的错误，说明你运行的是源码版的 `.bat`，请确认用的是 `.exe`。

## 四、行情头部字段释义

顶部行情条实时刷新，字段与口径如下：

| 字段 | 含义 | 口径说明 |
|---|---|---|
| **最新价** | 最新成交价 | 涨跌与涨跌幅均**相对昨结算价**计算（与交易所、主流期货软件一致） |
| **涨跌 / 涨跌幅** | 相对昨结算 | 例：昨结 1010，最新 1001 → `-9.0 (-0.89%)` |
| **开盘价** | 当日第一笔成交价 | 夜盘开盘即开始计入 |
| **最高价 / 最低价** | 当日最高 / 最低成交价 | 含夜盘 |
| **结算价** | 当日结算价 | **盘中为上一交易日结算价**，收盘后由交易所公布当日值 |
| **昨结算** | 上一交易日结算价 |涨跌幅基准 |
| **持仓量** | 未平仓合约数（双边） | 单位：手 |
| **成交量** | 当日累计成交（双边） | 单位：手 |
| **买价 / 卖价** | 买一价 / 卖一价 | 非交易时段可能为空（显示为 0 或 `-`） |
| **买量 / 卖量** | 买一量 / 卖一量 | 同上 |

> **为什么涨跌幅用昨结算而不是昨收盘？**
> 期货市场以结算价做每日盈亏结算，所以交易所和文华、博易等主流软件都用昨结算做涨跌基准。
> 而**分时图的基准线**用**昨收盘价**（与新浪分时图口径一致），两者口径不同是刻意为之。

## 五、周期与 K 线

支持 11 个周期：

| 周期 | 数据来源 | 数量上限 |
|---|---|---|
| **分时** | 当日分时走势 | 当日全部 |
| **1 / 5 / 15 / 30 / 60 / 120 分** | 上游分钟 K 接口 | 约 1023 根（上游单次上限） |
| **日 K** | 上游日 K 接口 | 全量历史（可回溯约 4~7 年） |
| **周 / 月 / 年 K** | **前端由日 K 合成** | 全量 |

**周 / 月 / 年 K 的合成规则**：

- 开盘价 = 该周期第一根日 K 的开盘价
- 最高价 = 该周期内最高价的最大值
- 最低价 = 该周期内最低价的最小值
- 收盘价 = 该周期最后一根日 K 的收盘价
- 成交量 = 该周期内成交量**求和**
- 持仓量 = 该周期**最后一根**日 K 的持仓量（期末值）

> **为什么分钟 K 只有约 1000 根？** 这是上游接口的单次返回上限，不是本程序的限制。
> **日 K 不受此限**，可以取到该合约上市以来的完整历史。

### 默认显示全量

所有周期**默认完整显示全部可用数据**（从最新一根往前铺满），不做截断。
如果你觉得太密，用滚轮或双指捏合放大即可。

## 六、主图指标

主图右上角可切换 5 种主图叠加指标：

| 指标 | 全称 | 说明 |
|---|---|---|
| **MA** | 移动平均线 | 默认显示 MA5 / MA10 / MA20 / MA60，四色区分 |
| **SAR** | 抛物线转向 | **红点画在 K 线下方 = 多头**；**绿点画在 K 线上方 = 空头**。图例同步显示当前多空状态 |
| **BOLL** | 布林带 | 上轨 / 中轨（20 日均线）/ 下轨，中轨为价格均线 |
| **EXPMA** | 指数平滑移动平均 | EXPMA5 / 10 / 20 / 60，比 MA 对近期价格更敏感 |
| **BBIBOLL** | BBI 布林带 | 以 BBI（多空指标，4 条均线平均）为中轨的布林带，比普通 BOLL 更平滑 |

> **关于 SAR 的颜色**：红绿点是**方向标识且位置分离**——多头点在下、空头点在上，
> 不是简单的红绿交替。这样即使色盲用户也能靠位置判断多空。

## 九、指数口径：加权 vs 主连

这是本项目最有价值的部分之一。右侧「同品种合约」标题栏有三个分段按钮：

### 仓权（默认）——本地持仓量加权指数

```
指数最新价 = Σ(合约最新价 × 合约持仓量) / Σ(持仓量)
指数昨结   = Σ(合约昨结价 × 合约持仓量) / Σ(持仓量)     → 涨跌口径与单合约一致
指数开高低 = 各字段同权重加权
成交量/持仓量 = Σ(各合约)
```

- 成分 = **该品种全部在交易的月份合约**（不是只取主力）
- **主力连续合约 XX0 不参与加权**（它只是主力月份的影子，纳入会重复计权）
- 代码形如 `SAW`（SA + W，W = Weighted），在合约列表**置顶**显示，带 `∑` 标识
- 权重明细随接口返回，可核查

### 量权——成交量加权指数

同上公式，把持仓量换成成交量。适合观察资金活跃度分布。

### 天勤——官方指数

调用天勤（快期）官方的 `KQ.i` 指数 / `KQ.m` 主连。需要配置账号（见[第十五节](#十五天勤快期账号配置)）。
未配置时该按钮自动置灰。

> **交叉验证**：本地持仓量加权指数与天勤官方指数在 5 家交易所 6 个品种上偏差全部 ≤ 0.041%，
> 说明本地算法是可信的。详见数据源说明文档。

### 加权指数的历史 K 线

加权指数支持**分时 / 1分~120分 / 日 / 周 / 月 / 年 K** 全部周期：

- **分钟线**：各成分合约分钟线按时间对齐后加权，缺失分钟用前收盘价填充
- **日 K**：逐根枚举**当时上市过的全部月份合约**，按**每根 K 线自身的持仓量动态加权**
  （因为主力月份会随时间轮换，用今天的名单去加权历史会严重漏算）
- **周 / 月 / 年 K**：由加权日 K 前端合成

加权日 K 每品种可回溯约 **1,600 ~ 2,014 根**（至 2018-06）。

## 十一、品种与合约列表

### 左侧品种列表

- 覆盖**中金所 / 上期所 / 大商所 / 郑商所 / 广期所**共 79 个品种
- 按交易所分组，**支持中文名或代码搜索**
- 品种中文名**自动取自主力连续合约的实时名称**（上游改名会自动跟随，无需维护常量表）
- **已停牌品种自动识别并置灰**：靠主力日 K 的最后交易日期判断（如强麦 WH、早籼稻 RI 停在 2022-2023 年）
- 点击品种即切换到该品种的**主力连续合约（XX0）**，右侧合约列表同步刷新

### 右侧同品种合约列表

- **加权指数（∑）置顶**
- 然后是**主力连续（XX0）**
- 接着是该品种**全部挂牌月份合约**
- **主力合约单独标注**（当前持仓量最大的月份）
- **已过期合约不展示**，只显示当前在交易的（与新浪财经一致）
- 点击任意行即切换

## 十五、天勤（快期）账号配置

**只有想用「天勤」档官方指数时才需要配置**。其余功能全部不需要账号。

### 获取账号

到 <https://account.shinnytech.com/> 免费注册一个快期账号。

### 配置方式

**EXE 用户**：把 `tianqin.json` 放在 **EXE 同目录**（外置配置优先于内置）：

```json
{
  "auth_user": "你的快期账号",
  "auth_pass": "你的快期密码",
  "enabled": true
}
```

- 想**停用**天勤：把 `enabled` 改成 `false`（或删掉外置文件回落到内置配置）
- **换账号不必重新打包**，改这个文件即可，下次查询自动生效

**源码用户**：在项目根目录放 `tianqin.json`，内容同上，然后重启。

## 十六、自己重新打包 EXE

```bash
# 一键打包（Windows）
打包.bat

# 或手动执行
python -m PyInstaller --clean --noconfirm 期货行情面板.spec
```

产物在 `dist/期货行情面板.exe`。

**打包要点**（改 spec 前务必看一遍，这几个坑都实际踩过）：

| 事项 | 说明 |
|---|---|
| **不要 exclude `numpy` / `pandas`** | `tqsdk/api.py` 顶层无保护地 `import numpy` / `import pandas`，排除后 tqsdk 直接不可用（体积从 22MB 涨到 74MB 就是这么来的） |
| **不要 exclude `unittest`** | tqsdk 依赖链会走到 `numpy.testing._private.utils`，那里顶层 import unittest |
| **tqsdk 是惰性导入** | PyInstaller 静态分析扫不到，必须用 `hookspath` 指定自定义 hook 补齐依赖 |
| **资源路径要区分** | 打包后 `__file__` 指向临时目录，只读资源要用 `sys._MEIPASS` |
| **保留控制台** | spec 里 `console=True` 便于排错，想要无窗口改成 `False` |

## 十七、常见问题

**Q：提示"行情接口异常"？**
多为网络问题或系统代理干扰。本程序已自动绕过系统代理直连；若公司内网封锁了新浪财经域名，请检查防火墙。

**Q：分钟 K 只有约 1000 根？**
上游接口单次上限约 1023 根，属数据源限制。日 K 不受此限。

**Q：加权日 K 第一次打开很慢（几秒到十几秒）？**
需要先枚举并拉取数十个月份合约的日 K 再逐根合成，结果有缓存；之后切周期都是瞬时的。

**Q：休市时数据不动？**
正常。休市期间自动降低刷新频率，夜盘 21:00 恢复。

**Q：双击 EXE 后等了十几秒才出界面？**
正常。单文件模式每次启动都要把约 74 MB 解压到临时目录，之后启动自检又要拉一次行情。

**Q：想改默认品种？**
`期货行情面板.exe --symbol RB2701`，或改 `启动面板.bat` 里的参数。

**Q：端口 8686 被占用怎么办？**
程序会自动顺延到 8687、8688……控制台会提示实际使用的端口。也可以手动 `--port 9000`。

**Q：手机能看吗？**
可以。用 `--host 0.0.0.0` 启动，手机浏览器访问 `http://<电脑局域网IP>:8686/`。界面支持触屏拖动与捏合缩放。

**Q：数据准确吗？**
行情来自新浪财经公开接口，与新浪网页一致；加权指数为本地自研算法，已与天勤官方指数交叉验证（偏差 < 0.05%）。**但数据仅供参考，不构成投资建议。**
