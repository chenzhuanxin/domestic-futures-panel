1核心功能

参照新浪财经期货行情页的版面设计，左边品种导航、右上合约列表、中间主图 + 双副图。

📈

全周期行情

分时、1 / 5 / 15 / 30 / 60 / 120 分钟、日、周、月、年 K。周月年 K 由日 K 合成，成交量求和、持仓量取期末值。

⚖️

自研加权指数

新浪没有加权指数，本项目用全部在交易合约按持仓量加权合成。支持仓权 / 量权 / 天勤三档口径切换。

📊

主图 5 种指标

MA、SAR（红绿双色点）、BOLL、EXPMA、BBIBOLL 一键切换，SAR 多空点按位置分离，色盲友好。

🧮

副图 6 种指标

MACD、KDJ、RSI、BOLL、WR、DMI。选择器位于副图二自身位置；BOLL 会同步叠加到主图。

🌏

全品种覆盖

79 个品种按交易所分组，支持中文名 / 代码搜索。停牌品种自动识别置灰，中文名自动跟随上游更新。

👆

触屏可用

滚轮缩放、拖动平移、单指滑动、双指捏合，方向键与快捷键俱全，手机平板也能用。

📐

分时轴自适应

横轴按整段交易时段铺满（刚开盘不会被拉伸），纵轴以昨结算为中心对称取整档百分比。

💾

配置记忆

深色 / 浅色主题、合约、周期、指标、指数口径全部写入本地，刷新后保持。

2快速开始

两种方式任选，EXE 连 Python 都不用装。

1
下载 EXE 从 Releases 下载 futures-panel-v1.0.0.exe，放到任意文件夹。
2
双击运行 会弹出控制台显示面板地址与行情连通状态，稍等几秒浏览器自动打开 http://127.0.0.1:8686/。
3
开始看盘 左侧选品种，右侧选合约，顶部切周期与指标。滚轮缩放、拖动平移、鼠标移入看十字光标详情。

源码运行（需 Python 3.8+）

后端是纯标准库实现，不需要 pip install 任何东西。

git clone https://github.com/chenzhuanxin/domestic-futures-panel.git
cd domestic-futures-panel
python server.py
首次启动较慢是正常的：单文件 EXE 每次启动都要把约 74 MB 解压到临时目录，需 5~20 秒。 关闭时关掉控制台窗口或按 Ctrl+C。

3加权指数：为什么自己算

新浪没有真正的加权指数（SA99 / SA888 实测为空），而加权指数比主力连续更能反映整个品种的真实价格水平。

指数最新价 = Σ(合约最新价 × 合约持仓量) / Σ(持仓量)
指数昨结   = Σ(合约昨结价 × 合约持仓量) / Σ(持仓量)   → 涨跌口径与单合约一致
指数开高低 = 各字段同权重加权
成交量/持仓量 = Σ(各合约)
口径权重说明
仓权（默认）持仓量与官方指数口径最接近，反映资金沉淀
量权成交量反映交易活跃度分布
天勤—调用天勤（快期）官方 KQ.i / KQ.m，需配账号
算法可信度：本地持仓量加权指数与天勤官方指数在 5 家交易所 6 个品种上 偏差全部 ≤ 0.041%（纯碱 1008.87 vs 1009.0）。
历史日 K 必须逐根动态加权：主力月份会随时间轮换，若用「今天的合约名单 + 固定权重」 去合成历史，会严重漏算——实测 2026-03-16 成交量低估约 200 倍。 正确做法是枚举历史上出现过的全部月份合约，按每根 K 线自身的持仓量加权。
